# Site Intelligence Hub

MASTER PROMPT — HUBTWINX™ SINGLE-PAGE WEBSITE

Create a premium, futuristic, highly polished single-page website for HubTwinX™, an intelligent Digital Twin platform developed by EnerSpace Technology LLP.

I will provide the HubTwinX logo with this prompt. Use the logo as the primary source for the website's visual identity, color palette, accent colors, gradients, typography direction, and overall brand language.

I will also provide the HubTwinX content/reference material. Treat that content as the source of truth for messaging and terminology. Do not invent technical claims, features, statistics, certifications, customers, or capabilities that are not supported by the supplied content.

1. CORE CONCEPT

Understand the relationship between the two products before designing anything:

PowerTwinX™ = Grid Side

PowerTwinX digitally represents the electricity journey:

Generation → Transmission → Distribution → Transformer → Smart Meter

It explains how energy moves through the power network and reaches the point of consumption.

HubTwinX™ = End-User / Site Side

HubTwinX continues the same digital journey beyond the meter:

Meter → Site → Infrastructure → Assets → Equipment → Energy → Intelligence → Control

Therefore, HubTwinX must NOT feel like a generic smart-home website.

It is a much broader:

SITE DIGITAL TWIN + ENERGY INTELLIGENCE + ASSET VISIBILITY + AI + IoT + AUTOMATION + CONTROL PLATFORM

It can apply to:

Homes

Villas

Apartments

Offices

Commercial buildings

Factories

Plants

Warehouses

Hospitals

Hotels

Campuses

Institutions

Energy sites

The central visual and storytelling idea should be:

"POWER REACHES THE SITE. HUBTWINX MAKES THE SITE INTELLIGENT."

The user should feel that PowerTwinX tells the story of how electricity gets there, while HubTwinX tells the story of what happens once it reaches the site.

2. WEBSITE EXPERIENCE

Build the entire website as one continuous visual story.

The page should feel like the visitor is travelling through a digital representation of a real physical site.

Use a narrative progression:

POWER → METER → SITE → ASSETS → DATA → DIGITAL TWIN → INTELLIGENCE → ACTION → AUTOMATION

Each section should visually transition into the next.

Avoid making the page feel like a collection of disconnected SaaS sections.
